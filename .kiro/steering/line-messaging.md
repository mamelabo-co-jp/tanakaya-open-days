# LINE 配信の安全ルール

LINE の配信は取り消せない。本番アカウントの友だちは実際のお客様。

- 本番アカウントへの配信は、依頼者が対象、文面、日時を明示して指示したときだけ行う
- 試験送信は、テスト用アカウント（友だちは田中さんだけ）にだけ行う
- LINE Bot MCP Server はテスト用アカウントのトークンで接続し、`line-tester` エージェントだけが使う
- 送信がタイムアウトしても再送しない。状況を依頼者に報告して判断を待つ
- 無料プランの上限は月200通。全員への配信は1回で友だちの人数分を数える。送る前に、その月の残りの通数を確かめる
- トークンをチャットに貼らない。ファイル、ログ、コミットに書かない
- `sam local invoke` で配信の関数を動かすときは、テスト用アカウントのトークンを使う
- 前日配信の Lambda を手で起動しない（`aws lambda invoke` と `sam remote invoke` は hook が止める）
